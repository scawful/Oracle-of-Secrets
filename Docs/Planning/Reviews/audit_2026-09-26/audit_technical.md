Main findings:
1. **The room-tag ID table is wrong in 4 places:** MEMORY "Key Patterns #9", `Docs/Technical/Room_Tag_Slots.md`, `goron_mines_minecart_design.md:119` and the comment at `Sprites/Objects/minecart.asm:1480-1492`.
